示意图：上面一行是自编码器，输入图经可学习的编码器压成一个不可读的潜向量，再由可学习的解码器还原成重建图。下面一行是代码自编码，目标图经优化求解拟合出一段可读、可执行的代码，再由固定的渲染器执行这段代码，画回重建图。三处不同：编码靠优化求解而不是学习，中间表示是代码而不是向量，解码器是固定的渲染器而不是可学习的网络。 Diagram. Top lane, an autoencoder: an input image goes through a learned encoder into an unreadable latent vector, and a learned decoder turns it back into a reconstruction. Bottom lane, code autoencoding: code is fitted to the target image by optimization, giving a readable, executable program, and a fixed renderer executes that code to draw the reconstruction. Three differences: the encoder is solved rather than learned, the intermediate is code rather than a vector, and the decoder is a fixed renderer rather than a learned network.
