Painting by Code

基于代码自编码的大语言模型图像生成Image Generation with LLMs via Code Autoencoding

我们用代码自编码把图片批量反编译成可执行的 Python 笔触程序，再用下一词预测（NTP）训练语言模型逐笔作画。

We decompile images into executable Python stroke programs through code autoencoding and train a language model to paint with next-token prediction (NTP).

TL;DR

图片生成是一个可学的代码生成任务：其中看图重建展现出稳定的 scaling；编辑与文生图也学到了基础，只是 scaling 缓慢。

Image generation is a learnable code-generation task: reconstruction scales steadily, while editing and text-to-image learn the basics but scale slowly.

  1. 可学且稳定。我们用标准 NTP 训练逐笔绘制，loss 平稳下降，没有 spike。在测试集上图片重建 PSNR 随着训练稳定上升，仍未见 ceiling。Learnable and stable. Under standard NTP training, the loss decreases smoothly without spikes. On the test set, image reconstruction PSNR rises steadily with training and shows no ceiling yet.
  2. 编辑与文生图任务相对较难，但仍能学到基础概念。文生图能抓到基本概念（天空、草地、主体的大致轮廓与配色），编辑能找到要改的部位并在那里落笔；只是画得粗，完成度和稳定性都还不够，PSNR 没有随训练步数上升。可能的原因有三个：文本描述不充分、模型容量不足、数据不足。Editing and text-to-image are relatively harder, but the model still learns basic concepts. Text-to-image captures basic concepts (e.g., sky, grass, and the rough shape and palette of the subject). Editing finds the region to change and paints there. However, the strokes remain coarse and lack completion and stability. As a result, PSNR does not increase with training steps. We consider three possible causes: insufficient captions, insufficient model capacity, and insufficient data.

01 · BACKGROUND前沿模型能够使用代码逐笔作画Frontier models can paint with code, stroke by stroke

2026 年 11 月 9 日 Fable 5.2 发布当天，“用代码画画”刷屏。@Mr_Salio 让它分五个阶段画 Anthropic CEO Dario Amodei；第二天，@SMK_12159 回帖“GPT 也能做这个”，画了 OpenAI CEO Sam Altman。两个前沿语言模型选了同一条生成路径：不调用图像模型，用代码一笔一笔地画。

On November 9, 2026, the day Fable 5.2 launched, “painting with code” went viral. @Mr_Salio asked it to paint Anthropic CEO Dario Amodei in five passes. The next day, @SMK_12159 replied “GPT can do this too” with a painting of OpenAI CEO Sam Altman. Both frontier language models took the same generation path: they called no image model and painted with code, stroke by stroke.

这两个例子说明，纯语言模型可以把绘画分解成能执行、能检查、能迭代的代码。视觉生成未必是扩散黑盒，也可以是一种带中间状态的推理过程。于是我们想问：

These two examples show that a pure language model can decompose painting into code that it can execute, inspect, and iterate on. Visual generation need not be a diffusion black box. It can also be a reasoning process with explicit intermediate states. We therefore ask:

能不能把“绘画”批量变成监督数据，直接把逐笔作画的能力训进模型权重，让模型一次写出完整的绘制程序？Can we turn “painting” into supervised data at scale, train stroke-by-stroke drawing directly into the model’s weights, and let the model write a complete drawing program in one go?

我们的做法是代码自编码：用拟合器把每张图片反编译成一段笔触程序（即逐笔作画的代码），再用固定渲染器执行这段程序，把图片画回来。这样，任意一张图片都能自动变成一条“图片–程序”训练样本，无需人工标注。我们再用这些样本训练语言模型，让它学会自己写出笔触程序。

Our approach is code autoencoding. A fitter decompiles each image into a stroke program (i.e., code that paints the image stroke by stroke), and a fixed renderer executes the program to draw the image back. In this way, any image becomes an image–program training pair without manual labels. We then train a language model on these pairs to write stroke programs itself.

02 · RESULTS图片生成是一个可学的代码生成任务Image generation is a learnable code-generation task

我们用代码自编码得到的笔触程序训练语言模型，具体做法见第 3 节。训练过程中，我们按先后保存了七个检查点（C1–C7），并在模型没有见过的测试集上测试每个检查点。

We train a language model on the stroke programs from code autoencoding (Section 3 gives the details). During training, we save seven checkpoints in order (C1–C7) and evaluate each one on a test set that the model has never seen.

模型逐渐学会用代码重建图片The model gradually learns to reconstruct images with code

PSNR 衡量重建图和原图有多接近：数值越高越像，大约每提高 3 dB，像素误差减半。从 C1 到 C7，平均重建 PSNR 从 8.78 dB 升到 17.44 dB，提高了 8.66 dB，相当于像素误差降到原来的约七分之一。把相邻两个检查点逐张比较，后一个检查点在大多数图片上画得更像。这条曲线至今没有变平。

PSNR measures how close a reconstruction is to the original image: higher means closer, and every gain of about 3 dB halves the pixel error. From C1 to C7, the average reconstruction PSNR rises from 8.78 dB to 17.44 dB. This gain of 8.66 dB cuts the pixel error to about one seventh. When we compare two adjacent checkpoints image by image, the later one paints closer to the original on most images. The curve has not flattened yet.

编辑与文生图更难学习，但仍学到基础Editing and text-to-image are harder to learn, but the model still learns the basics

与重建不同，编辑与文生图的分数并不乐观：编辑的平均 PSNR 从 17.05 缓降到 15.06 dB，文生图在 8.8–9.3 dB 横盘。但是，文生图能抓到基本概念，用大色块搭出天空、草地和主体轮廓；编辑也能找到要改的部位，在对的地方落笔（图 3、图 4）。问题出在后面：细节画不准，指令常做不完，编辑还容易画过头。目前提升的是这些仍很粗糙的基础能力，分数还没有反映出来。可能的原因有三个：

Unlike reconstruction, editing and text-to-image do not improve in score: the average editing PSNR decreases from 17.05 to 15.06 dB, while text-to-image remains within 8.8–9.3 dB. However, text-to-image captures basic concepts and lays down the sky, grass, and subject shapes in broad color blocks. Editing finds the region to change and paints in the right place (Figures 3 and 4). The failures come afterwards: details are inaccurate, instructions are often left unfinished, and editing tends to overpaint. At this stage, the gains lie in these still crude basics, which the scores do not yet reflect. There are three possible causes:

（a）文本描述不充分。(a) Captions are insufficient. 文生图的 prompt 多是数据集里的短描述，对构图与配色的监督不足；编辑指令也常含糊。Most text-to-image prompts are short dataset captions that underspecify composition and palette. Editing instructions are often vague as well.

（b）模型容量不足。(b) Model capacity is insufficient. 重建依赖视觉与代码的对齐；编辑和文生图还需要理解指令、规划空间。基础已经有了，但要画得准、做得完，可能需要更大的模型。Reconstruction relies on the alignment between vision and code, while editing and text-to-image additionally require instruction understanding and spatial planning. With the basics in place, painting accurately and finishing instructions may require a larger model.

（c）训练数据不足。(c) The data are not enough yet. loss 还在下降，未见 ceiling，模型远没有训饱；基础已经学到，更多整图长序列数据可能同时提高准确度和完成度。The loss is still decreasing with no ceiling, which indicates that training is far from saturated. More data, especially long whole-image sequences, may improve accuracy and completion together.

03 · METHOD将图片反编译成代码Decompiling images into code

上面的结果都建立在大量“图片–程序”训练样本之上，这些样本来自代码自编码。如果把一张图片看作一段程序运行的结果，图片重建就是反编译：给定像素，恢复产生它的笔触程序。这些程序由拟合器求解得到，无需人工标注。

The results above rely on a large number of image–program training pairs, which come from code autoencoding. If an image is the output of a program, reconstruction is decompilation: given the pixels, we find the stroke program that produced them. A fitter solves these programs without manual labels.

笔触虚拟机极简：画布上只有三类原语，即椭圆、胶囊和矩形。每一笔由中心、长短轴、角度、透明度与调色板颜色决定。一段程序有几百到一千多笔，渲染结果即目标图的近似。

The stroke VM (i.e., the virtual machine that executes stroke programs) is minimal: its canvas has only three primitives, namely ellipses, capsules, and rectangles. Each stroke is determined by its center, axes, angle, opacity, and palette color. Rendering a program of a few hundred to over a thousand strokes approximates the target image.

同一套笔触语言和同一个渲染器，配上不同的题目，就构成三个任务；训练数据覆盖重建、编辑和文生图。

The same stroke language and the same renderer support three tasks that differ only in their inputs. The training data cover reconstruction, editing, and text-to-image.

拟合器每次保留降误差最多的一笔The fitter keeps the stroke that most reduces the error

三个任务用到的笔触程序都由拟合器求出。用多尺度笔触由粗到细地“画”出一张图，最早由 Hertzmann 系统化提出Hertzmann, SIGGRAPH 1998.
查看参考文献；更早的交互式雏形见 Haeberli 1990Haeberli, SIGGRAPH 1990.
查看参考文献。Hertzmann 每笔的颜色直接从原图采样，其余参数用启发式确定；我们则按增益（即这一笔带来的误差下降）对每一笔做联合优化。

The stroke programs for all three tasks come from the fitter. Painting an image coarse to fine with strokes of multiple sizes was first systematized by HertzmannHertzmann, SIGGRAPH 1998.
View reference, with an earlier interactive precursor by Haeberli in 1990Haeberli, SIGGRAPH 1990.
View reference. Hertzmann samples each stroke color from the source image and sets the other parameters by heuristics. In contrast, we jointly optimize each stroke by its gain (i.e., the error reduction it brings).

由粗到细。大笔先铺轮廓与色块，中笔修正结构，小笔只在仍不够像的地方补纹理。

Coarse to fine. The fitter first lays down silhouettes and color blocks with large strokes. It then fixes the structure with medium strokes and adds texture with small strokes only where the render still deviates from the image.

残差落笔。在残差最大处搜索位置与形状（长宽比）；哪一笔让当前渲染与原图的误差降得最多，就保留哪一笔。

Residual placement. The fitter searches the position and shape (i.e., aspect ratio) of a stroke where the residual is largest. It keeps the stroke that most reduces the error between the current render and the original image.

梯度定角度。角度取自图像梯度，颜色由最小二乘闭式解求出。

Angle from the gradient. The fitter takes the stroke angle from the image gradient and solves the color in closed form by least squares.

留下的笔触按顺序编译成整数笔触程序，再用 PSNR 门槛筛掉拟合失败的样本，剩下的就是训练数据。

We compile the kept strokes in order into an integer stroke program and drop failed fits with a PSNR threshold. The remaining programs form the training data.

拟合器和渲染器合在一起，就是标题里的代码自编码。它和自编码器（autoencoder）一样，先把图片转换为中间表示，再重建图片。不同的是，这里的中间表示是可读、可执行的笔触程序，由优化拟合得到，再交给固定渲染器执行。

Together, the fitter and the renderer form the code autoencoding in the title. Like an autoencoder, it maps an image to an intermediate representation and then reconstructs the image. In contrast, the intermediate representation here is a readable and executable stroke program, obtained by optimization and executed by a fixed renderer.

04 · TRAINING DYNAMICS训练 loss 平稳下降，没有 spikeTraining loss decreases without spikes

每条程序是一段纯文本，只有笔触正文计 lossThe loss is computed only on the stroke code

拟合器留下的每条程序收成一段纯文本。前缀（任务、档位、画布定义；编辑另带输入图）不计 loss，笔触正文计 loss。我们用标准 NTP 训练，并定期保存检查点，评估它们在测试集上的表现。

Each program kept by the fitter becomes a piece of plain text. We exclude the prefix (i.e., the task, the tier, and the canvas definition, plus the input image for editing) from the loss and compute the loss only on the stroke code. We train with standard NTP and periodically save checkpoints to evaluate their performance on the test set.

两组训练 loss 都持续下降，但七个检查点在测试集上的表现表明，三项任务的改善程度并不一致。

Both training losses keep decreasing. However, the performance of the seven checkpoints on the test set shows different progress across the three tasks.

05 · LIMITATIONS局限Limitations

本文仍有几点局限。一方面，我们只评测了一个模型规模，且 PSNR 只与单张参考图逐像素比较，因此模型容量的影响尚未验证，这一指标对文生图也偏严格。另一方面，全部训练程序来自同一个拟合器，模型会继承它由粗到细的作画习惯，PSNR 门槛也会丢弃拟合失败的样本。

There are still several limitations in this post. On the one hand, we test only one model size and compute PSNR on a single reference image, which leaves capacity effects untested and is strict for text-to-image. On the other hand, all training programs come from one fitter, whose coarse-to-fine habits the model inherits and whose PSNR threshold drops failed fits.

06 · CONCLUSION结论Conclusion

本文用代码自编码训练语言模型逐笔作画：拟合器把图片反编译成可读、可执行的笔触程序，固定渲染器再把程序画回图片，语言模型则用标准 NTP 学习写出这些程序。实验表明，图片生成是一个可学的代码生成任务：图片重建的 PSNR 随训练稳定上升，仍未见 ceiling；编辑与文生图也学到了基础概念，只是 scaling 缓慢。

This post trains a language model to paint stroke by stroke through code autoencoding. A fitter decompiles each image into a readable, executable stroke program, a fixed renderer draws the program back, and the language model learns to write such programs with standard NTP. The results show that image generation is a learnable code-generation task. Reconstruction PSNR rises steadily with training and shows no ceiling yet, while editing and text-to-image learn basic concepts but scale slowly.
